# (compression-codec, secure-secrets-vault, autograd-engine, markov-chatbot-cli, etc).

# copy this file to the project root as `.gitignore`, delete sections that don't apply
# to that project's stack (e.g. drop "Node" if it's a pure-Python project, drop
# "Rust" unless there's a cargo crate involved), and add project-specific entries
# at the bottom under "# Project-specific" (e.g. benchmark corpus caches, generated
# vault files, model checkpoints).
